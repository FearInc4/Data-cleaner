Sign-in apps (Google & Microsoft)

Each install uses its own OAuth app, so your mailbox access belongs to you and nobody else. One-time setup, about 5 minutes per provider. {% if not base_url_configured %}These redirect URIs use the address you're on now ({{ base_url }}). If you reach Data Cleaner at another address, set DATACLEANER_BASE_URL.{% endif %}

{% for app in apps %}

{{ provider_icon(app.provider.key) }} {{ app.provider.name }} {% if app.configured %}configured{{ " via environment" if app.from_env }}{% else %}not set up{% endif %}

{% if app.provider.key == "google" %}
  1. Open Google Cloud Console and create a project (any name).
  2. Enable the Gmail API.
  3. Go to Google Auth Platform → Branding, fill in an app name and your email. Under Audience, choose External and add yourself as a test user.
  4. Under Data Access, add the scopes gmail.send and gmail.readonly.
  5. Under Clients, create a Web application client with this redirect URI: {{ app.redirect_uri }}
  6. Paste the client ID and secret below.
  7. Optional but recommended: under Audience, press Publish app. Apps left in "Testing" have to be reconnected every 7 days. You'll see an "unverified app" notice when you connect; that's expected for your own private app.
{% else %}
  1. Open App registrations and choose New registration.
  2. Supported account types: Accounts in any organizational directory and personal Microsoft accounts.
  3. Redirect URI: platform Web, {{ app.redirect_uri }}
  4. Under Certificates & secrets, create a client secret and copy its Value.
  5. Under API permissions → Microsoft Graph → Delegated, add Mail.Send, Mail.Read, User.Read, offline_access.
  6. Paste the Application (client) ID and secret value below.
{% endif %} {% endfor %}
